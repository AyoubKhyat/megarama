# Megarama Marrakech — Concept Site

A cinematic premium website concept for Megarama Marrakech (cinema chain). Built as a design exploration in immersive web presentation for a premium entertainment brand.

**Status:** Design concept / portfolio demo. Not affiliated with the real Megarama company.

## What it demonstrates

- Cinematic hero with 3D scene
- Scroll-driven storytelling
- Movie showcase pages
- Modern typography and layout system
- Motion design (Framer Motion + GSAP)

## Tech stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **3D:** Three.js
- **Animation:** Framer Motion + GSAP

## Project structure

```
megarama/
├── src/app/
│   ├── movies/         # movie showcase pages
│   ├── layout.tsx
│   ├── page.tsx        # cinematic homepage
│   ├── robots.ts
│   └── sitemap.ts
└── public/
```

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000
